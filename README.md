# 个人健康运动管理平台 (Personal Health and Sports Management Platform)

> 🎓 **毕业设计（论文）项目**：个人健康运动管理平台的设计与实现  
> 💻 **技术栈**：SpringBoot 契约兼容 RESTful 服务 + Vue 3 响应式 + Element Plus + MySQL 8.0 + 大语言模型 (GenAI) 赋能  
> 📑 **项目汇报 PPT**：详见根目录下 [`个人健康运动管理平台_毕设总结报告.pptx`](docs/个人健康运动管理平台_毕设总结报告.pptx)

## 📖 项目简介与设计初衷

随着大众健康运动意识的提升，跑步、骑行、器械健身与健康饮食记录逐渐成为刚需。然而多数用户仍面临：
1. **记录分散零乱**：随手记在备忘录中，无法沉淀为连续的健康数据；
2. **缺乏能量收支算法**：只记录文字，无法自动折算卡路里消耗与今日热量差（能量天平）；
3. **商业软件臃肿**：大型商业 App 充斥着电商广告与付费推销，缺乏轻量好用的个人体征记录工具。

本项目专为日常健康打卡与运动管理打造，打通**“今日摄入 - 今日消耗 = 净卡路里差”**的动态能量天平，并深度结合大语言模型实现**通俗易懂的阶段性运动周报与个性化锻炼建议**。

## 🌟 核心功能架构

```
个人健康运动管理平台
├── 用户前台系统 (User Client)
│   ├── 📊 综合数据总览：今日能量天平、4大核心指标(体重/BMI/BMR/推荐饮水)、近7天柱状走势大盘
│   ├── 🤖 AI 运动健康分析：大模型周报总结、量化分析点评、个性化运动建议(严守非医疗诊断红线)
│   ├── 🩺 身体数据录入：身高、体重、BMI自动换算、高低血压、心率历史归档
│   ├── 🏃 日常运动健身打卡：运动项目选择、时长、自动折算消耗卡路里、配速里程与心得
│   ├── 🥗 健康饮食分餐管理：早中晚加餐分餐记录、热量计算与三大营养素(蛋白质/碳水/脂肪)
│   ├── 🎯 运动目标与计划：阶段Flag目标设定、动态完成百分比进度条、快速打卡推进
│   └── 👤 个人健康档案：身高、体重、目标体重与联系方式维护
└── 管理员后台系统 (Admin Panel)
    ├── 🏢 全平台概览大盘：全站注册总用户数、全站打卡总次数、全站累计消耗热量统计
    ├── 👥 用户档案管理：用户信息表格、模糊搜索、一键 Switch 账号封停与超管防误删保护
    ├── 🏃 运动打卡监管：全平台各用户打卡流水穿透审查、异常违规数据删除
    ├── 📢 公告发布管理：向全平台发布健康科普、运动技巧或系统升级通告
    └── ⚙️ 运动字典维护：配置运动分类、运动名称及其每分钟参考消耗系数
```

## 🗃️ 数据库设计 (MySQL 8.0)

系统在 MySQL 中设计了 8 张核心关系数据表（完整 SQL 脚本位于 `sql/health_platform.sql`）：

1. **`sys_user`**：用户与管理员认证表（支持普通用户 `USER` 与管理员 `ADMIN`，含 `status` 状态控制）
2. **`body_metrics`**：基础身体体征历史表（身高、体重、自动计算 BMI、收缩压、舒张压、静息心率）
3. **`sport_dict`**：基础运动数据字典表（运动名称、分类、每分钟参考卡路里系数）
4. **`workout_record`**：日常运动打卡流水表（运动项目、训练时长、消耗卡路里、里程、心率、心得）
5. **`diet_record`**：饮食分餐摄入表（早中晚餐次、食物名称、热量、三大营养素）
6. **`exercise_plan`**：运动计划与阶段目标表（目标值、当前累计进度、完成百分比、达成状态）
7. **`ai_suggestion_record`**：**AI 建议与分析记录表**（大模型生成的阶段周报总结、锻炼建议与免责声明）
8. **`system_notice`**：系统公告与健康指南表（科普指南、系统通知、发布人与时间）

## 🚀 本地运行与部署指南

### 1. 环境依赖
* Python 3.10+
* MySQL 8.0+ / MariaDB 10.5+
* 现代浏览器（Chrome、Edge、Safari、Firefox）

### 2. 数据库初始化
```bash
# 创建数据库并导入初始结构和种子数据
mysql -u root -p -e "CREATE DATABASE health_platform DEFAULT CHARACTER SET utf8mb4;"
mysql -u root -p health_platform < sql/health_platform.sql
```

### 3. 安装依赖与启动服务
```bash
# 创建并激活虚拟环境
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt

# 启动服务
uvicorn app.main:app --host 0.0.0.0 --port 8090
```

服务启动后，浏览器打开 `http://localhost:8090/` 即可访问。
